# 🏥 UniqueHealthID

A **Complete Healthcare Web Application** built with **Next.js 14, TypeScript, and Tailwind CSS** – designed to provide users with seamless access to medical records, doctor information, health metrics, and emergency services in one modern platform. 🚀

---

## 📂 Project Structure & Setup

* **Framework**: Next.js 14 (App Router) with TypeScript
* **Styling**: Tailwind CSS + Custom Animations
* **Icons**: Lucide React
* **Design**: Responsive (Mobile, Tablet, Desktop)

---

## ✨ Core Features

### 🏠 Home Page

* Banner Slider (4 rotating healthcare themes)
* Navigation Cards for all modules
* Health Metrics Quick Access (Heart Rate, Temperature, Oxygen, Blood Pressure)
* Emergency System Quick Access (Ambulance, SOS, SOS Contact)
* Doctor Info Section with appointment links
* Call-to-Action sections with gradient designs

### 📋 Medical Archive

* Manage complete medical records
* Search and filter functionality
* Record detail modals with file attachments
* Support for multiple record types: consultation, lab, prescription, vaccination, surgery
* Status tracking (Active, Completed, Pending)

### 👨‍⚕️ Doctor Information

* Detailed Doctor Profiles with ratings & reviews
* Appointment Scheduling with calendar integration
* Doctor search and filtering
* Contact info, availability, education, and certifications

### 📊 Health Metrics

**Four detailed monitoring pages:**

* ❤️ Heart Rate – Real-time charts & trends
* 🌡️ Temperature – Fever tracking + tips
* 🫁 Oxygen Rate – SpO₂ monitoring with safe ranges
* 💉 Blood Pressure – Systolic/Diastolic tracking

Each page includes: current readings, statistics, charts, recent logs, and health tips

### 🚨 Emergency System

* 🚑 Emergency Ambulance – One-tap 911 call + location sharing
* 📢 SOS Alert – Send emergency alerts to contacts
* 📇 SOS Contacts – Manage emergency contact list

### 🔐 Authentication System

* Login & Signup with **beautiful gradient UI**
* Real-time form validation
* Social Authentication (Google, Apple)
* Secure session handling

## 🚀 Getting Started

### Prerequisites

* Node.js (v18+)
* npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/UniqueHealthID.git

# Navigate to the project
cd UniqueHealthID

# Install dependencies
npm install
# or
yarn install
```

### Running the App

```bash
npm run dev
# or
yarn dev
```

➡️ The app will be live at: **[http://localhost:3000](http://localhost:3000)**
